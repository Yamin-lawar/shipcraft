## What the runs found and fixed
1. No readout before the first decision, no proposed design with alternatives, the design summary buried in a prompt: now three required plain-text messages, and a free check (`TC-STRUCTURE`) that enforces them.
2. Greenfield: cross-cutting areas were skipped silently, which looks like forgetting: each must now be stated in one line, even as "not applicable, because...".
3. **PRD not found:** the skill used a search tool and missed the hidden `.craft/` folder, so it asked for a PRD that existed. The shared rule now says to list with a shell command, never a search tool. (This also protects `craft-prd`.)
4. The ending sometimes lacked the closing line: the exact line is now in the skill.
5. The captured PRD was rewritten without a history copy: now stated in the intake rules.
6. Checks that were wrong, not the skill: question marks inside code (SQL placeholders) counted as questions, and the judge reply's stray braces broke parsing.

## Rubric note
The plan-conversation criterion "feasibility and reuse" read as "reuse existing code", which cannot apply to a new product. I clarified it (what the platform or ecosystem gives for free counts) and re-scored the saved greenfield run: 3.83 became 4.17. This is a judgement call you may disagree with.
