# Rubric: Parity between hosts

Compared by a person on the same scenario in both hosts. Text is never identical, so judge *equivalence*, not wording.

| Criterion | Pass when |
|---|---|
| steps | Same steps in the same order |
| decisions | Equivalent decision points, with equivalent recommended answers |
| files | The same files written to `.craft/` |
| artifacts | Final artifacts both meet the artifact rubric |
| manual steps | Any difference is explained by a row in `shared/host.md` |
