# Example: recurring tasks

One feature, taken through the planning half of Shipcraft, in a small fictional task app (Node, SQLite, a daily digest job on `node-cron`).

| File | What it is | Where it came from |
|---|---|---|
| [brief.md](brief.md) | the result of `/craft-explore` | a hand-written reference example, the quality bar for briefs |
| [prd.md](prd.md) | the result of `/craft-prd` | a hand-written reference example, the quality bar for PRDs |

The brief and PRD are reference examples that skills aim for; real runs produce documents of the same shape (see [evals/results](../../../evals/results/)). The hand-off and Plan are real output. Read them with a critical eye: the Plan is long, and we are not claiming it is perfect.
